## 📖 Understanding speculative decoding

This software uses DFlash speculative decoding. This technique uses a small secondary model to predict the next words before the main model processes them. By verifying several words at once, the application reduces the time spent waiting for the model to think. You will notice the text prints to the screen in large chunks rather than one word at a time. This technology is essential for running 31B models on home hardware at usable speeds.
